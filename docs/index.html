安装说明 ↗

  1. 下载并解压

    从 GitHub 下载 Windows x64 ZIP，完整解压后运行 DarkestDungeonSaveEditor.App.exe。

  2. 备份并载入

    关闭游戏并保留独立备份，在编辑器中选择游戏路径与目标存档，再载入当前存档。

  3. 预览后确认

    查看修改预览，确认目标与结果。应用时编辑器会先备份存档，再执行写入。

当前发布为测试版本。Windows 包已包含 .NET 运行时，正常使用无需 Java；请保留解压后的全部文件。
