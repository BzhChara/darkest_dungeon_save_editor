# Darkest Dungeon Save Editor v0.1.0-beta.2

This prerelease adds an English UI alongside Simplified Chinese and improves the battle-map context menus.

## Changes since v0.1.0-beta.1

- **English and Simplified Chinese UI:** windows, menus, tooltips, dialogs, previews, status messages, and editor-generated errors use shared language resources.
- **Compact Language menu:** use the **Language** button beside **Support** to choose **Follow system**, **Simplified Chinese**, or **English**. The preference is remembered and takes effect after restarting the editor. Follow system selects Simplified Chinese for a Chinese Windows UI language and English otherwise.
- **Bilingual content names:** game and Mod names prefer the UI language, with fallback to the other supported language or the original ID. Both languages remain searchable.
- **Clearer battle-menu icons:** consistent icon sizes and spacing, original map artwork read from the game installation, and vector icons for editing actions and missing artwork. Game images are not bundled.
- **Language-independent diagnostics:** issue classification and write eligibility use stable identifiers where required, so changing translated wording does not change those decisions.
- **Packaging checks:** the Windows download includes the Chinese resource assembly, and packaging rejects builds that omit it.

## Download and requirements

- Download **DarkestDungeonSaveEditor-v0.1.0-beta.2-win-x64.zip** from this release's assets, extract the entire archive, and run `DarkestDungeonSaveEditor.App.exe`.
- Requires **Windows 10/11 x64**, a local Darkest Dungeon installation, and **Java 8 or newer** on `PATH`.
- The **.NET 8 runtime is included**. A separate .NET installation is not required. Java is not bundled.
- Keep all extracted files together, including the `zh-CN` resource directory and the `tools` folder.
- `SHA256SUMS.txt` contains the ZIP's SHA-256 checksum. In PowerShell, run `Get-FileHash -Algorithm SHA256 .\DarkestDungeonSaveEditor-v0.1.0-beta.2-win-x64.zip` and compare the complete hash.
- Read `START-HERE.md` inside the package for installation, backups, and troubleshooting. The automatically generated **Source code** downloads require building the project.

## Updating and editing saves

Close the editor and extract this release into a new folder. Do not mix files from different versions. Existing workspaces, backups, and the language preference remain under `%LOCALAPPDATA%\DarkestDungeonSaveEditor`.

Keep a separate save backup and confirm the selected profile. Close Darkest Dungeon before the initial load or any write. Read the preview and confirmation carefully. Explicit loading may prepare missing Mod manifests, and eligible battle placement may install or update the managed Encounter Bridge.

The existing save editing, automatic synchronization, previews, backups, and guarded-write workflow remain available. This prerelease does not claim compatibility with every Mod. Special scripted encounters, ambush/teleport behavior, and hidden/story maps remain partly unsupported. External tool output, operating-system errors, and user or Mod text can retain their original language.
