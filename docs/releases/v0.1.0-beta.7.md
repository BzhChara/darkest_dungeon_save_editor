# Darkest Dungeon Save Editor v0.1.0-beta.7

This prerelease improves quest-board layout Mod support, mouse targeting, map zoom controls and artwork refresh.

## Changes since v0.1.0-beta.6

- Read quest-board spacing, offsets, region progression, detail text anchors and reward grid settings from the effective game and enabled Mod definitions. Respect actual image dimensions instead of imposing vanilla task-icon sizes.
- Match task clicks to the visible artwork, including transparent overlaps. Right-click a task to replace or delete it, a region heading to create a quest there, or empty background for the region menu.
- Show both quest-board and dungeon-map zoom relative to their default view: **100%** restores the minimum/default framing. Remove the duplicate Fit control, and preserve zoom and panning across language changes and full-map transitions.
- Keep long quest descriptions and objectives inside their configured text areas with ellipsis, in both embedded and full-map views. Extra reward rows remain scrollable.
- Resolve dungeon artwork through the enabled Base/DLC/Mod sources and manifest rules. Refresh same-path replacements and provider changes without stale decoded images.
- Include quest-board and dungeon artwork in the common content-change workflow. Same-path replacements refresh decoded images, click bounds and content lists. The attempted artwork-only refresh optimization is retained as commented code for future performance work and is not enabled in this release.
- Use the existing load, pre-operation and game-exit check boundaries. No background resource-scanning loop or extra right-click check is added.
- Make ordinary contract-test entry points use the C# codec by default, including content synchronization and JSON escaping checks. Historical Java comparison modes remain separate from routine validation.

## Packages

- **Editor:** `DarkestDungeonSaveEditor-v0.1.0-beta.7-win-x64.zip`.
- **Optional MO2 patch:** `DarkestDungeonSaveEditor-0.1.0-beta.7-MO2-patch.zip`. Apply its payload to the matching beta.7 editor; retain your own `mo2-compat.json`. The supported merge mapper remains `game_support_DarkestDungeon_20261016_004446`.
- **Standalone converter:** `DarkestDungeonModOrderConverter-0.1.0-beta.7-win-x64.zip`. Rebuilt with the shared Core; its interface and conversion rules are unchanged.
- Verify downloads against `SHA256SUMS.txt`. The editor and converter include the Windows x64 .NET 8 runtime and do not require Java for normal use.
- Workshop folders remain `editor/`, `optional-patches/` and `utilities/`. Copy the editor outside Workshop before applying the MO2 patch so Steam cannot overwrite the replacement component.

## Validation and local data

Validation covers native C# synchronization, resource overlays and image replacement, quest layout and click targeting, map viewports, and MO2 replacement-Core compatibility. Layout checks include the installed Compact Quest Screen Mod. These UI/resource changes do not add new save-writing rules; this release does not claim another full in-game acceptance run or support for every UI Mod.

Backups, working copies and language preferences are under `%LOCALAPPDATA%\DarkestDungeonSaveEditor`. Session logs and an optional `mo2-compat.json` are beside the standalone editor executable. Keep backups and unresolved recovery evidence. See the [installation guide](../release-installation.md).
