# Darkest Dungeon Save Editor v0.1.0-beta.5

This prerelease aligns resource identity handling with the game, fixes quantity editing for saved aliases, limits wallets to two billion, and corrects effective-source labels. The optional MO2 package also fixes virtual file numbering when a profile contains enabled group headings.

## Changes since v0.1.0-beta.4

### Native resource identity and resolution

- Buffs, quirks, and trinkets resolve native hash aliases using their respective game rules instead of rejecting every collision. Buffs and quirks select the last matching definition; trinkets select the first matching eligible definition in resolved native file order.
- Effect-to-quirk references follow native hash identity. Repeated Effect declarations retain the previous disease assignment when that field is omitted, and an explicit empty assignment clears it.
- Existing saved quirk aliases count toward per-hero limits. Existing saved trinket aliases count toward owned copies and definition-limit warnings.
- Hash collisions whose result is established by the native rules are reported as information. Missing files, uncertain load order, unresolved dependencies, unsafe HP, and stale previews retain their guards.

### Quantity editing, wallets, and source labels

- Town and expedition quantities use native saved type/ID hashes consistently during loading, refresh, preview, and writing. Editing an existing alias updates its saved records and preserves their other fields.
- Wallet targets range from `0` to `2,000,000,000`, matching the game's cap. Existing wallet totals use wider arithmetic before applying that cap; reducing an over-cap balance removes the hidden excess. Estate quantities and expedition stack/capacity rules keep their existing limits.
- English and Chinese source labels identify the definition that actually took effect. They distinguish a same-path file replacement from native first-match or last-match definition selection.

### Optional MO2 compatibility package

- MO2 group headings with the case-sensitive `_separator` suffix are ignored as content layers, including headings marked with `+`. They no longer shift virtual filenames or overwrite's layer index.
- The package includes the same native identity, wallet, and source-label fixes as the ordinary editor.
- The supported mapper remains `game_support_DarkestDungeon_20261016_004446`, tested with the supplied MO2_2.5.3b bundle.

### Standalone Mod Order Converter

The converter is rebuilt as beta.5 with the matching shared Core component. Its interface and conversion rules have not changed in this release.

## Packages and updating

- **Editor:** extract `DarkestDungeonSaveEditor-v0.1.0-beta.5-win-x64.zip` into a new folder and run `DarkestDungeonSaveEditor.App.exe`.
- **Optional MO2 patch:** apply `DarkestDungeonSaveEditor-0.1.0-beta.5-MO2-patch.zip` to the beta.5 editor, following its README. Preserve your `mo2-compat.json`; the ZIP supplies an example only. Replace the older patch DLL with this matching version.
- **Standalone converter:** extract `DarkestDungeonModOrderConverter-0.1.0-beta.5-win-x64.zip` into a separate folder and run `DarkestDungeonModOrderConverter.exe`. Keep its DLLs separate from the editor.
- Verify downloads against `SHA256SUMS.txt`. The editor and converter include the .NET 8 runtime and require Windows 10/11 x64. Normal use does not require Java.
- Keep the editor's `zh-CN`, `tools`, and `licenses` folders. Workshop subscribers receive the ordinary editor in `editor/`, the optional patch in `optional-patches/`, and the converter ZIP in `utilities/`. Copy the editor outside the Workshop directory before applying the MO2 patch so Steam updates do not replace your patched files.

## Local data folder

Paste `%LOCALAPPDATA%\DarkestDungeonSaveEditor` into File Explorer's address bar. It normally expands to `C:\Users\<your Windows user>\AppData\Local\DarkestDungeonSaveEditor`.

- `backups/`: automatic pre-write save backups.
- `workspaces/`: decoded working files, previews, and recovery evidence. The default MO2 content cache is `workspaces/mo2-compat/`.
- `language.json` and `mod-order-language.json`: language preferences.

Keep backups you may need and retain working files during troubleshooting or interrupted-write recovery. After recovery is complete and the editor is closed, unused MO2 cache snapshots can be removed and rebuilt when needed. This directory is separate from the actual game saves. Standalone session logs and optional `mo2-compat.json` configuration are beside the editor EXE.

## Validation and limitations

The functional changes passed the complete native regression suite before the final shared-wallet display adjustment. Final-source checks then passed 25 quantity groups, 18 inventory-persistence groups, and 31 MO2 compatibility contracts. Coverage includes isolated DSON preparation and commits, saved hash aliases, metadata preservation, stale-definition rejection, wallet boundaries, source labels in both languages, and MO2 separator mapping. Independent read-only review found no remaining substantive issue in the quantity fix.

These tests and the documented native-code evidence do not establish compatibility with every Mod or MO2 fork. No new live-game test was performed for the final quantity fix. Missing Mod translations remain content issues; this release does not add translations to third-party Mods. Existing scripted-encounter and hidden/story-map limitations remain.
