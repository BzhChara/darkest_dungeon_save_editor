# Darkest Dungeon Save Editor v0.1.0-beta.4

This prerelease changes when the editor synchronizes saves, adds immediate language switching, and updates the optional MO2 compatibility package. It also stops profile loading early when an enabled Mod is missing.

## Changes since v0.1.0-beta.3

### Loading and synchronization

- Loading resolves the save's enabled Mods before generating manifests or scanning resources. Missing local Mod titles and Workshop IDs are listed together, and loading stops instead of continuing with an incomplete catalog. Synchronization uses the same guard.
- Continuous background content scans are replaced by checks on load, before previews and writes, after edits, and once after the game exits. A lightweight process check disables loading and editing while the game runs.
- Editing remains disabled until post-edit or post-game synchronization finishes. A failed synchronization requires an explicit reload instead of repeatedly retrying in the background.
- Table selection stays consistent after synchronization and language changes. Moving between town and an expedition clears the previous context's item target, including returning to town through the editor.
- The beta.3 hotfix for official manifest directory entries is included. Directory records require a valid path, zero size, and an existing directory; ordinary file validation remains enforced.

### Battle editing and interface

- Opening map menus and browsing candidates use the loaded snapshot without a full resource scan. Confirmed map writes still validate current saves, Mod bindings, and resources before committing, then wait for synchronization.
- Newly generated Encounter Bridge directories use ASCII names, and display titles use ASCII parentheses. Existing legacy directories or titles are not migrated automatically and require separate cleanup and recreation.
- English and Simplified Chinese switch immediately. New installations follow the Windows UI language by default; an explicit saved choice still takes precedence.
- Dialog styling and the support QR presentation have been refined.

### Optional MO2 compatibility package

- The separate replacement component targets `game_support_DarkestDungeon_20261016_004446`, tested with the supplied MO2_2.5.3b bundle.
- Content mapping follows the updated Buff, localization, rules, rarity, and inventory behavior. Plain localization XML retains its physical path; virtual aliases resolve to the enabled MO2 providers or generated overwrite files.
- Repeated binding validation reuses a verified cache without rebuilding it or repeatedly checking unrelated cached catalogs. Write-specific resource checks remain active.
- Missing saved Mods stop loading before the adapter reads resource contents or materializes its merged source. The check uses the save's enabled list, normally `merge mod` plus any separate Bridge, rather than expecting every MO2 Mod to be named in the save.

### Separate Mod Order Converter

The repository also includes a standalone tool under `tools/Mo2ModlistConverter` for transferring enabled Mod membership and priority between native saves and MO2 lists. It previews mappings and exports new files without overwriting its inputs. Its language menu and controls match the editor, and a successful export consumes the preview. It is available as a separate download and is not installed into the editor.

## Packages and updating

- **Editor:** extract all of `DarkestDungeonSaveEditor-v0.1.0-beta.4-win-x64.zip` into a new folder and run `DarkestDungeonSaveEditor.App.exe`.
- **Optional MO2 patch:** apply `DarkestDungeonSaveEditor-0.1.0-beta.4-MO2-patch.zip` to that beta.4 editor, following the patch README. Preserve your configured `mo2-compat.json`; the package supplies an example file only. Do not reuse an older replacement DLL.
- **Standalone Mod Order Converter:** extract `DarkestDungeonModOrderConverter-0.1.0-beta.4-win-x64.zip` into its own folder and run `DarkestDungeonModOrderConverter.exe`. Do not copy its DLLs into the editor. The converter's README describes the import and export steps.
- Verify all three downloads against the release's `SHA256SUMS.txt`. The editor and converter include the .NET 8 runtime and require Windows 10/11 x64. Normal use continues to use the native C# codec without Java; the editor's explicit JAR reference mode remains available.
- Keep the editor's `zh-CN`, `tools`, and `licenses` folders. See `START-HERE.md` for installation, backups, logs, and update instructions.

## Validation and limitations

The functional changes passed the native regression suite with 250 checks before version promotion. MO2 coverage includes 29 isolated contracts for mapping, missing providers, deferred preparation, cache integrity, and source validation. The standalone converter passed 24 contracts and a bilingual WPF layout smoke test. Package validation checks the replacement component against the exact packaged editor's API and identity, and verifies the archive contents and checksums.

These checks do not establish compatibility with every Mod, MO2 plugin fork, or in-game workflow. The complete recipient MO2 battle/save-write workflow still needs in-game confirmation. Scripted encounters, special ambush/teleport behavior, and hidden/story maps retain the existing limitations.
