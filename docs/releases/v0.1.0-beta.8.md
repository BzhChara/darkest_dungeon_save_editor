# Darkest Dungeon Save Editor v0.1.0-beta.8

Item, trinket and hero previews now run in the background. You can move or close the editor while it prepares a preview. Apply becomes available when the current preview is ready. Changing the selection or starting the game discards the pending result.

## Maps and scene changes

- Returning to the quest board reuses its map and artwork. Changes to the profile or its active resources still refresh the board at the next synchronization.
- Returning to town switches directly from the expedition map to the quest board. The activity log reports the new scene and asks you to select an item again only if the active Items tab lost its selection.
- Fixed expedition controls that could stay disabled after a map edit. Force completion and force return become available after synchronization when the current expedition supports them.
- The encounter and initial-quirk pickers close when their profile becomes unavailable or the game starts.

## Save safety and town events

- Save writes check for both supported game process names before replacing files. Closing the editor cancels pending previews and waits for active writes and recovery to finish.
- Force completion and force return share file replacement and recovery logic. Encounter Bridge updates replace only changed files and preserve unrelated or externally modified files during rollback.
- Event currency grants use the same wallet identity and 2,000,000,000 limit as item editing. Explicit event quests use the quest board's checks for their type, region, objectives and rewards. An existing matching quest stays on the board.

## Downloads

- **Windows x64 editor** — extract `DarkestDungeonSaveEditor-v0.1.0-beta.8-win-x64.zip` and run `DarkestDungeonSaveEditor.App.exe`.
- **Optional MO2 patch** — apply `DarkestDungeonSaveEditor-0.1.0-beta.8-MO2-patch.zip` to the beta.8 editor and keep your own `mo2-compat.json`. The supported mapper is `game_support_DarkestDungeon_20261016_004446`.
- **Standalone Mod Order Converter** — extract `DarkestDungeonModOrderConverter-0.1.0-beta.8-win-x64.zip` to its own directory. This build includes the beta.8 shared Core.

Verify downloads against `SHA256SUMS.txt`. Workshop subscribers can find the editor in `editor/`, the MO2 patch in `optional-patches/` and the converter in `utilities/`. Copy the editor outside the Workshop directory before installing the patch so Steam updates cannot replace it.

Backups, working copies and language preferences are stored under `%LOCALAPPDATA%\DarkestDungeonSaveEditor`. Session logs are beside the editor executable. [Installation and local data guide](../release-installation.md).
