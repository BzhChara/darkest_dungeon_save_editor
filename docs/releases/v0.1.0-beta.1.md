# Darkest Dungeon Save Editor v0.1.0-beta.1

The first public prerelease of the standalone Windows editor for offline Darkest Dungeon saves.

## Download and requirements

- Download **DarkestDungeonSaveEditor-v0.1.0-beta.1-win-x64.zip** from this release's assets, extract the entire archive, and run `DarkestDungeonSaveEditor.App.exe`.
- Requires **Windows 10/11 x64**, a local Darkest Dungeon installation, and **Java 8 or newer** on `PATH`.
- The **.NET 8 runtime is included**. A separate .NET installation is not required. Java is not bundled.
- `SHA256SUMS.txt` contains the ZIP's SHA-256 checksum. In PowerShell, run `Get-FileHash -Algorithm SHA256 .\DarkestDungeonSaveEditor-v0.1.0-beta.1-win-x64.zip` and compare the complete hash.
- Read `START-HERE.md` inside the package for installation, backups and troubleshooting. The automatically generated **Source code** downloads require building the project.

## Included features

- Town and expedition item quantities, trinket creation, and stagecoach hero generation with level and quirk selection.
- Battle-map inspection and supported movement, battle, curio, treasure, trap and obstacle operations, including the managed Encounter Bridge.
- Active game, DLC and Mod content catalogs with English and Simplified Chinese game names.
- Automatic save synchronization. The first synchronization completes within **Load current save**; periodic full resource checks run at one-minute intervals while the window is active.
- Guarded previews, stale-save and content checks, DSON round-trip validation, full profile backups and transaction recovery.
- Session logs with grouped catalog diagnostics and corrected encounter slot messages.

## Before editing a save

Keep a separate backup and confirm the selected profile. Close Darkest Dungeon before the initial load or any write. Read the preview and confirmation carefully. Explicit loading may prepare missing Mod manifests, and eligible battle placement may install or update the managed Encounter Bridge.

This prerelease does not claim compatibility with every Mod. Special scripted encounters, ambush/teleport behavior and hidden/story maps remain partly unsupported. The application UI is currently localized in Simplified Chinese; project documentation is in English.
