# Darkest Dungeon Save Editor v0.1.0-beta.9

This prerelease updates compatibility with the official game's resource loading and runtime behavior, including the Ode to Mods update. It corrects existing editor assumptions as well as supporting newly documented behavior.

## Hero generation and town events

- Combat skill unlocking and equipment use separate passes. Ordinary heroes equip unlocked skills in class declaration order; guaranteed, hidden, forced and slot-exempt skills follow their authored rules. Event recruits retain valid unlocks beyond the equipped skill limit, including at level zero.
- Initialize quirk evolution periods and retain the actual randomly selected quirk definition through HP and recruit initialization. Random draws, named selection and act-out binding follow their respective duplicate-definition rules.
- Recognize special quirk sources reached through effects, Buffs and camping. Missing effective source files leave the relevant analysis incomplete.
- Support `specific_recruit` as one offer at the requested resolve level. Paid embark Buff interactions require the native combination of Buff, cost and interaction artwork.

## Item sources and maps

- Follow reachable combat Effects and Buffs through `gain_loot`, including actor reactions, trinket triggers and sets, traits, districts, town activities, world sources and `last_hero`. Apply each consumer's own field names, file queries, list limits and duplicate handling.
- Find valid nested town-building resources for both item-source and currency analysis. Missing or malformed effective inputs retain incomplete-analysis diagnostics, while independent confirmed sources remain usable.
- Combine base map pools with additions for the selected expedition difficulty. Difficulty changes refresh choices and invalidate stale previews.
- Preserve the Daze turn-order flag in native save round trips and unrelated edits.

## Loading diagnostics

File checks distinguish data/translation candidates from loaded catalog entries and name `modfiles.txt` explicitly. Loading can generate a missing manifest with the official tool; existing manifests are not automatically expanded. Full logs retain file paths and diagnostic reasons.

## Downloads

- **Windows x64 editor** — extract `DarkestDungeonSaveEditor-v0.1.0-beta.9-win-x64.zip` and run `DarkestDungeonSaveEditor.App.exe`.
- **Optional MO2 patch** — apply `DarkestDungeonSaveEditor-0.1.0-beta.9-MO2-patch.zip` to the beta.9 editor and keep your own `mo2-compat.json`. The supported mapper remains `game_support_DarkestDungeon_20261016_004446`.
- **Standalone Mod Order Converter** — extract `DarkestDungeonModOrderConverter-0.1.0-beta.9-win-x64.zip` into its own directory. It includes the matching shared Core; its conversion rules are unchanged.

Verify downloads against `SHA256SUMS.txt`. Workshop contains the runnable editor under `editor/`, the MO2 patch ZIP under `optional-patches/`, and only the converter ZIP and checksum under `utilities/`; no duplicate extracted converter is included. Copy the editor outside Workshop before applying the MO2 patch so Steam updates cannot replace it.

Keep a separate save backup and close the game before writing. Compatibility evidence comes from the official executable and isolated editor/save regressions; this release does not claim a new live-game acceptance run or support for every Mod.
